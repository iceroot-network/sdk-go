# IceRoot SDK (Go)

The Go SDK for IceRoot, for exchanges, custodians and other Go services. It embeds the Rust core of the IceRoot SDK compiled to WebAssembly and runs it in pure Go, so every format and signature matches the Rust and TypeScript SDKs byte for byte.

The SDK is in early development and not yet published as a tagged module.

[Contributing](https://github.com/iceroot-network/.github/blob/prod/CONTRIBUTING.md). Work on `dev`. Production changes reach `prod` through a reviewed `dev` → `prod` pull request.
